# Project Overview

Static landing page project for a Russian travel/car-with-driver service in Saint Petersburg and Leningrad Oblast.

Current structure:
- `index.html`: main page entrypoint.
- `style.css`: site styles.
- `script.js`: browser JavaScript.
- `assets/`: local visual assets, including the provided driver photo and a reference design image.

There is no package manager, build step, framework, or Git repository in the current folder.
