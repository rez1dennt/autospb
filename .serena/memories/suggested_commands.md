# Suggested Commands

Windows PowerShell:
- List files: `Get-ChildItem -Force`
- Fast file list: `rg --files`
- Read a file: `Get-Content -Raw index.html`
- Serve static site locally with Python if installed: `python -m http.server 8000`
- Check Git status if repository exists: `git status --short`

No npm/cargo/pip build, lint, or test commands are configured in this project.
